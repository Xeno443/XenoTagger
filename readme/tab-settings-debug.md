# Settings – Debug

A single switch controlling whether the [Debuglog](tab-debuglog.md) tab
is available.

![Settings – Debug overview](images/settings-debug.png)

- **Enable Debuglog tab (requires app restart)** - unchecked by default.
  When unchecked, no log handler is attached at all, avoiding any
  logging overhead. Checking this box and saving does not show the
  Debuglog tab immediately - click **Restart app** (bottom of the
  Settings page) or relaunch manually for it to appear.
